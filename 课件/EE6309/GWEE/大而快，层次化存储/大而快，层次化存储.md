## 术语

- MAR: Memory address register
- MBR: Memory buffer register
- MDR: Memory data register
- Word: The “natural” unit of organization of memory. Common word lengths are 8, 16, and 32 bits.
  字长一般是内存和处理器处理数据的最小单位（也可能不是），而且长度是不定的（甚至可能不同于总线位宽或者处理器位数），所以如果有题目没有明确说明字长是多长，建议去抽他大嘴巴子。
- Memory cycle: When CPU needs to read a word from memory, either an instruction or data, it loads the address of the word it wants into the MAR and sends a read signal to the memory. After one memory cycle, the memory puts the desired word in the MBR where the CPU can take it out and use it.
  所以Memory Cycle就是CPU将地址放进MAR后，到MBR数据可用的时间。书上对这块分得更细，但在Gwee的世界观下Memory Cycle Time和Access Times相同，舍去了额外的延迟。
- Meta bit (tag bit, valid bit, flag bit): It is an extra bit associated with each cell (or location) to indicate its content. e.g. 0 for instruction, 1 for data. It can also be used to distinguish the data type, for example, floating point numbers or integers etc.
  用来做标记的乱七八糟的小玩意
- Reference: 内存引用，内存访问

# 内存交织

## Bank

*实际上这里并不是垃圾佬捡内存条时遇到的那个Bank*

这里很单纯就是一组排列好的，能够被寻址的内存单元。按照这门课的惯例，一个地址对应一个word

## High Order Interleave

![[Pasted image 20250412184501.png#pic_75center|High Order Interleave]]

- 地址结构：$\text{<Bank Select> <Address within the selected bank>}$

If the CPU and I/O devices use different banks of memory for their instruction and data, all the banks can be accessed simultaneously with different ports and buses. In this manner, the overall speed performance of the computer can be effectively increased.

如果 CPU 和 I/O 设备分别使用不同的内存bank来存储指令和数据，那么所有的内存bank可以通过不同的端口和总线同时访问。通过这种方式，计算机的整体速度性能可以得到有效提高。（比较像哈佛结构）

### 例子

In certain pipeline processing systems, instructions and operands are placed in two different modules (banks) to enable the parallel processing (overlapping) of the instruction fetch cycle and the reading of the operand.
在某些流水线处理系统中，指令和操作数被放置在两个不同的内存bank中，以实现指令取周期和操作数读取的并行处理（重叠处理）

## Low Order Interleave

![[Pasted image 20250412185446.png#pic_75center|]]

- 地址结构：$\text{<Address within the selected bank> <Bank Select>}$

In this configuration, consecutive addresses are in alternate banks such that each device (CPU or I/O) will need to access all the banks in order to execute instructions or data. The computer can overlap consecutive memory accesses. After the CPU has requested access to the first word in bank 1, it can move to bank 2 while the memory management unit is still waiting for the retrieval of the first word in bank 1. The CPU continues in this manner from one bank to the next. By the time the CPU returns to bank 1, the retrieval of the first word in bank 1 should be completed and the retrieval of the next word in bank 1 can be initiated. In this manner, the memory access can be greatly speeded up to the speed of the CPU.

在这种配置中，连续的地址会分布在交替的内存bank中，因此每个设备（CPU 或 I/O）都需要访问所有的内存bank才能执行指令或数据。计算机可以重叠连续的内存访问。当 CPU 请求访问内存bank 1 中的第一个字时，它可以转向内存bank 2，而内存管理单元仍在等待从内存bank 1 中检索第一个字。CPU 以这种方式从一个内存bank继续到下一个。当 CPU 返回到内存bank 1 时，内存bank 1 中第一个字的检索应该已经完成，并且可以启动对内存bank 1 中下一个字的检索。通过这种方式，内存访问的速度可以大大加快，达到与 CPU 的速度相匹配的程度。（类似流水线，提高了吞吐量）

### 例子

CPU频率200M，内存访问时间50nS

CPU时钟周期5nS，所以要10个内存bank流水线Low Order Interleave来达到CPU的吞吐量。

# 层次化存储

- The part of the operating system that supervises the flow of information between all storage devices is called the memory management unit (MMU).
- The objective of a MMU is to minimize the cost per bit of storage for a given performance requirement.
- This objective of a MMU is normally achieved by using a hierarchical memory, which consists of several levels of different types of memories of different speeds and costs.
- The function of a MMU is therefore to adjust the frequency with which the various memories in the hierarchy are referenced (accessed) to provide an efficient method of data transfer between these memories so as to maximize the utilization of all computer components with respect to speed and cost.

## 二级存储

- Let $t_{\text{A1}}$ and $t_{\text{A2}}$ be the system access times to $M_1$ (main Memory) and $M_2$ (Secondary memory) for a reference respectively. The average system access time for a word is: $$\begin{align}\displaylines{t_{\text{A}}=& Ht_{\text{A1}}+(1-H)t_{\text{A2}} \\ t_{\text{A1}}=& t_{\text{M1}} \\ t_{\text{A2}}=& t_{\text{B}}+t_{\text{A1}} \\ t_{\text{B}}=& b_s\times t_{\text{M2}}}\end{align}$$
  where:
	- $H$: Hit ratio
	- $t_{\text{B}}$: Block transfer times from $M_2$ to $M_1$
	- $b_s$: Block size

稍作推理（打开$t_{\text{B}}$），假设$\text{Block Size}=1\text{Word}$，能够得到：$$t_{\text{A}}=t_{\text{M1}}+\left(1-H\right)t_{\text{M2}}$$

## Access Efficiency

定义：$$e=\frac{t_{\text{A1}}}{t_{\text{A}}}=\frac{1}{H+(1-H)\frac{t_{\text{A2}}}{t_{\text{A1}}}}$$

# 相联存储器 Associative Memory

- Concept : The time required to find an item (data or instruction) in a memory can be reduced considerably if the stored item can be identified for access by content instead of by its address.
- 一种随机存储器，它允许对一个Word中的指定bit（通过Key Register进行掩码）进行检查匹配，能够同时在所有Word中进行。因此，这货是通过它的内容而不是地址进行检索。

- This type of memory is known as Content Addressable Memory (CAM).
- Memory cells in a CAM are accessed simultaneously within **one memory cycle** on the basis of data content rather than by a specific address or location to obtain the data required.
- The search for the required data in the memory can be done on the entire word or on a specific field within a word.
- It is more expensive than a normal memory as each cell must be equipped with storage capability as well as logic circuits for matching its content with an external argument.
- It is used mostly in applications where the search time is very critical.
- Applications: Password or Image Matching

# 虚拟存储

由于每个程序直接在裸的物理内存上跑非常不现实（各种入口处理非常困难），所以聪明的大聪明们弄出了虚拟存储。

在单个应用看来，自己的内存空间都是连续的，即使这些内存在实际的物理内存中并不连续。操作系统和MMU通过重定向共同创造了这个虚拟的世界，让应用以为自己在一段连续的内存中，从而世界大同。

虚拟的内存空间可以远比物理内存大，碎片化的组织也可以尽可能地利用实际的物理内存。当然了，具体的实现过程取决于不同的CPU和不同的操作系统。将虚拟地址转化为物理地址的过程被称为地址的翻译（Translate）

## 术语

- **Virtual address**: An address used by a programmer for a program. It is also known as a **logical address**.
- **Address space**: It refers to the virtual address space. It is also known as **name space**.
- **Physical address**: An address in main memory (or physical memory). It is also known as **real address**
- **Memory space**: It refers to the main memory address space.

## 页

- 这是一种在存储器中使用的技术，通过将存储器分成大小相同的部分来执行碎片化管理。在虚拟地址空间的部分被称为页（Page），在物理地址空间的部分被称为帧（Frame）。

![[Pasted image 20250412211551.png#pic_50center|空闲的内存塞不进更多的进程了！]]

- 在页出现之前，大聪明们对内存的管理是连续的，每个进程享有一段独立且连续的分区，但是当空闲的空间不足以继续连续分配内存后，就无法加载更多的进程了。

![[Pasted image 20250412211627.png#pic_50center|页能够充分利用内存的碎片空间]]

- 所以大聪明们将这些分区继续打碎变成更小的部分，建立起逻辑地址到物理地址的映射。即每一个页（Page）都对应一个帧（Page Frame），自然地，页和帧的大小也是相同的。
- 在分配内存时，使用分页能够保证内存的浪费少于1个页的大小，那么平均一下就是1/2个页的容量可能会被浪费。大大小于以前的浪费。

## 段

*Segmentation Error（*

- 页的存在固然大大提高了虚拟存储管理的效率，但假设有一个情况：有一段代码包含了两个同样的过程（过程是一个计算机概念，可以认为是子程序）。从效率最高的做法出发，我们应该给这个过程设计一个入口，每次调用都从这个入口进入。这样只需要一段内存就能让两个地方使用这个过程。当然了，这么好的事没法直接达成，即使我们有了页这一工具页做不到。
- 所以大聪明们发明了段，段包含了一大堆页，从而实现了更高层级的抽象，更高的难度和更高的效率。很显然，我们的抽象层级正在逐渐提高。

- 段的一大特点就是其长度是可变的，而不是页的固定长度。从它需要处理子程序的角度出发，这是自然需要具备的特性，不然子程序长度变了咋办。并且段暴露在用户空间中，而页在内核空间；所以段能够被用户感知并使用，页对于用户来说是透明的。

- 你可以想象编译的时候一个函数就会被创建一个段，给出入口地址就能把这玩意塞进去

### 段表映射

- 还是出于我们最本质也是最想做的事情：**应用看到的地址一定要连续！** 分段映射的地址处理也和分页处理非常类似。*由于段本质上是对页的一种抽象，我们甚至可以认为这是在对页号又进行了一次页表（虽然这不好，段不是多级页表，性质不一样，但能够辅助我们理解这一过程）*
- 对于大部分情况，我们都是把一个应用拆分成段，然后再把段分页。完成了自顶向下的过程。

- 所以我们还是能够把逻辑地址分成：**段号+页号+页内地址**的形式。唯一的不同是开头变成了段号+页号，而不是单纯的页号。而映射的最终结果应该还是**帧号+帧内地址**的形式。

![[Pasted image 20250412215732.png#pic_center|]]

- 看这张段表映射的图，虽然看起来很像将页号又页表了一次，但核心不同在于：**段号与页号是相加的，并非拼接**。这让段与页的关系变为了：**入口+偏移量** 的形式，这就实现了段能够将同一段过程映射到程序的不同地方。

- 可以把这么划分的页号也想像成一个偏移量，而段号就代表了程序真正的入口地址。那么不同的段号就意味着程序在不同的地方引用的过程。而页号这一偏移量加在段号上，保证了在这一段中程序的顺序运行，也就保证了程序行为是统一的。
- 通常段表中还需要保存一个段有多长，这样操作系统才能明确知道我们是否超出了范围，以及更多的保护措施。
