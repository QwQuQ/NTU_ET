
| 内容             | 并行化                                | 流水线                       |
| -------------- | ---------------------------------- | ------------------------- |
| Efficiency $E$ | $\frac{S(n)}{n}$                   | $\frac{N}{N+M-1}$         |
| Speedup $S$    | $\frac{n}{1+(n-1)F}$               | $\frac{M\times N}{N+M-1}$ |
| Throughput $b$ | $\frac{nb_S}{1+\left(n-1\right)F}$ | $\frac{N}{(M+N-1)T_p}$    |
| M              |                                    | 流水线级数                     |
| N              |                                    | 需要的操作数                    |
| n              | 并行度                                |                           |
| F              | 非并行概率                              |                           |

CPI: $$\text{CPI}=\frac{1}{E}$$
Amdahl’s law: $$\frac{n}{1+(n-1)F}$$
MIPS: $$\text{MIPS}=\frac{f}{\text{CPI}\times10^6}\text{MIPS}$$
