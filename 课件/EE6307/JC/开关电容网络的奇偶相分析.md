# 节点的电荷量

**基础知识**：在开关电容电路中，每次开关过程必定会伴随电荷的流动，并且最终平衡。电容器两个极板携带的电荷量相同，极性相反。极板的电压与极板携带的电荷无关（例如连接到地的极板可能带有负电荷）

分析开关电容网络时首先要找到一个守恒的节点，这个节点应该能保存电荷（也就是课件第40页提到的memory charge）。那么能够总结出这类节点的特征：不连接到源、运放输出端、地等能够流失电流的节点。一个典型的例子就是开关电容积分器中$C_2$与运放负输入端的节点（图中为$V_x$）。
![[Pasted image 20250327223347.png#pic_50center|]]
根据电荷守恒原理，在开关过程后，这一节点的电荷量（charge left）应该是开关前的电荷量（memory charge）与开关后变化的电荷量（contribution charge）之和。

如果在$0$时刻进行开关，假设电荷转移不消耗时间（$0^+$表示瞬态过程后，$0^-$表示瞬态过程的初始状态，$0$表示瞬态过程中的变化），我们可以得到：$$q_{\text{equilibrium}}\left(0^+\right)=q_{\text{memory}}(0^-)+q_{\text{contribution}}(0)$$

# 从连续时间，到离散时间，到奇偶相的离散时间

很显然的一点是，在开关电容电路中，从连续时间到离散时间的过程并不显然（甚至不是良定义的），对于不同的电路情况也是不同的。在这里假设某一开关在$t=t_n-\tau$时刻导通，在$t=t_n$时刻关断；而另一开关在$t=t_n+\frac{T}{2}-\tau$时刻导通，在$t=t_n+\frac{T}{2}$时刻关断。

## 解决奇偶相离散序列的定义

对于开关电容积分器的输入采样序列和输出序列，我们可以发现它们的采样时刻并不相同，时间差为$\frac{T}{2}$.

一个离散时间系统是不能平移$\frac{T}{2}$的（整数集的相邻整数之间是什么，当然是虚空）。但是我们可以用重建的操作来获得平移$\frac{T}{2}$后的新序列（这一过程并不是一个LTI系统）。

考虑一个离散序列$x[n]$，它对应的z变换为$X(z)$。对$x[n]$进行2倍时间扩展，可以得到新的序列为：$$x_{(2)}[n]=\left\lbrace{\displaylines{ x[n/2] \\ 0 }}\right. \xleftrightarrow{z} X(z^2)$$
此时的新序列有一大堆0，所以通过乘一个理想低通滤波器（带宽$-\frac{n\pi}{2}\to\frac{n\pi}{2}$）进行内插。假设低通滤波器的频谱为$H(z)$，在这一操作后可以得到新的对应关系为：$$x_{(2)}^\prime[n]\xleftrightarrow{z}X(z^2)H(z)$$
为了对新序列进行抽取操作，需要对序列进行时移，所以可以得到新序列为：$$x_{(2)}^\prime[n+1]\xleftrightarrow{z}X(z^2)H(z)z$$
现在对这一新序列进行抽取，为了描述这一行为，需要将z变换转变为傅里叶变换（由于现实世界采样得到的信号总是存在傅里叶变换，所以这一步成立，$z=e^{j\omega}$），由于此时理想低通滤波器的带宽变为$-n\pi\to n\pi$，和正常的周期相同，所以可以舍去，最终得到：$$x^\prime[n]=x_{(2)}^\prime[2n+1]\xleftrightarrow{\mathcal{F}}X(e^{2j\omega/2})H(e^{j\omega/2})e^{j\omega/2}=X(z)z^{1/2}$$也就是说奇偶序列z变换之间的转化可以通过乘$z^{1/2}$实现

至此我们解决了奇偶序列看似不符合z变换性质的问题，并且保证了任意一个奇/偶序列都有其对应的偶/奇序列。
