- A Structured Query Language (SQL) injection attack occurs on a databasedriven website when the hacker manipulates a standard SQL query.
  当黑客操纵标准的 SQL 查询时， 基于数据库驱动的网站上会发生结构化查询语言（SQL）注入攻击发生。
- It is carried by injecting a malicious code into a vulnerable website search box, thereby making the server reveal crucial information.
  通过在易受攻击的网站搜索框中注入恶意代码，从而使服务器泄露关键信息。
- This results in the attacker being able to view, edit, and delete tables in the databases. Attackers can also get administrative rights through this attack.
  这使得攻击者能够查看、编辑和删除数据库中的表格。通过此类攻击，攻击者还可以获取管理员权限。
- To prevent a SQL injection attack:
	- Use an Intrusion detection system, as they are designed to detect unauthorized access to a network.
	  使用入侵检测系统，它们旨在检测未经授权的网络访问。
	- Carry out a validation of the user-supplied data. With a validation process, it keeps the user input in check.
	  对用户提供的数据进行验证。通过验证过程，它可以保证用户输入受控。
